# Case Study Source

## Premise

How can a classic story become a measurable digital experience rather than a static promotional website?

## First release

The first release establishes the landing invitation, the scroll-driven Rabbit Hole and the Crossroads choice architecture. It demonstrates the funnel from awareness to acquisition to interaction without pretending that synthetic portfolio metrics are campaign results.

## Next evidence

Milestone 02 will add the Cheshire quiz, server-authoritative scoring, lead capture and session recovery. Milestone 04 will add the visually distinct analytics dashboard, segment matrix and synthetic CTA experiment.
